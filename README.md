# 数据库代码生成器

## 功能介绍
本工具可以通过连接数据库，自动生成对应的repository相关文件，包括：
- 数据库实体对象（Entity）
- 数据库映射文件（.xml）
- Repository接口文件
暂只支持增、删、改和通过主键查询

## 使用说明

### 1. 配置数据库连接
在项目根目录下创建 `application.properties` 文件，配置以下信息：
- 数据库连接配置  可修改指定的数据库
- 要生成相关代码的表名（多个表名用逗号分隔）
- 生成的实体对象、mapper、repository 路径配置  dstp项目修改修改example即可
- 生成的文件路径配置
